QuadMotion Showcase
terminal pixel-art engine

Four pixels per cell.
Zero flicker.

QuadMotion compiles pixel grids into Unicode quadrant glyphs ▘▝▀▖▌▞▛▗▚▐▜▄▙▟█, solves the two-colors-per-cell limit, and plays hold-timed animation in a fixed-height box with diffed, DEC 2026-synchronized frames. Everything below is drawn from the engine's real compiled cells.

      pipeline
      
How a frame is made

    

    

      
grid
Draw at 2× resolution
One character per sub-pixel; a terminal cell holds 2×2. Rigs are JSON, scenes are code on a sub-pixel canvas.

      
solve
Two colors per cell
Transparent stays background; the majority color becomes foreground, so a body cell with one eye pixel compiles to ▛, not an inverted ▗. A third color folds to the nearest.

      
encode
16 masks → glyphs
Bits TL=1, TR=2, BL=4, BR=8 pick one of 16 quadrant glyphs. Neighbouring cells with equal colors share one SGR run.

      
play
Diff + DEC 2026
Fixed height, only changed rows rewritten, the frame wrapped in ESC[?2026h … l so the terminal applies it at once.
